# Reference Animation Brief

The supplied reference presents a dark midnight-blue identity field with a small luminous humanoid at the center. The human is bright, pale, and almost holographic, with the surrounding field carrying the visual weight rather than the figure itself.

The core environment is a large semi-transparent spherical shell built from many thin latitude/longitude-like arcs, curved orbital paths, fine connective lines, and sparse star-like points. The shell has layered depth: a nearer cyan/teal translucent volume, a broader blue wireframe globe, and multiple elliptical orbits that continuously rotate or drift at different rates.

Inside the field, data records appear as small floating translucent square panels with luminous blue diamond/gem symbols. They are distributed around the human at varied depth and scale, with uppercase category labels such as IDENTITY, ACADEMIC, EMPLOYMENT, MEDICAL, FINANCIAL, LEGAL, and CORPORATE. Record panels gently bob, rotate, and pulse rather than behaving like flat UI cards.

Outside the protected sphere, organization nodes sit in the dark space at left, right, and lower peripheral positions. Each organization is represented by a small outlined geometric tower/container with a purple-blue inner core and a readable organization label. Fine consent paths connect these external nodes toward selected internal records, with moving points of light traveling along the paths. Peripheral prompts communicate that a node can grant consent.

The visual rhythm is continuous and spatial: slow shell rotation, orbit drift, record bobbing, faint particle twinkle, subtle node pulsing, and traveling consent particles. The scene should feel like a living network rather than a static 3D illustration. Landing and authenticated HOME should share this same field language, while preserving SAMVID’s existing touch-to-expand/minimize state machine, permission creation, revocation fragmentation, navigation, authentication, and organization gateway behavior.

Implementation constraint: reproduce the reference animation language and composition as an original SAMVID WebGL treatment; do not copy external assets, exact branding, or proprietary code. Use the existing React Three Fiber scene and additive layers where practical, with a lighter mobile path and prefers-reduced-motion handling.
